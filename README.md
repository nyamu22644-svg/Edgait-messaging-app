## 🎯 **NEW EXCLUSIVE FEATURES**

### 🔄 **Gaited Mode** - Smart Text Replacement
Ever receive messages with the wrong amount? Gaited Mode automatically replaces specific text patterns when messages arrive. Perfect for:
- **Converting currency amounts** (e.g., Ksh1.00 → Ksh100.00)
- **Standardizing sender names** (e.g., "M-PESA" → "Mobile Money")
- **Replacing keywords** in incoming messages

**How it works:** Set up sender-specific rules once. Every message from that sender automatically displays your custom text without changing the original message.

### 👻 **Scary MF Mode** - Temporary Message Editor
Want to temporarily change how a message looks without actually editing it? Scary MF Mode lets you:
- Long-press any received message
- Edit what it displays on your screen
- Revert automatically after a set time (5 min - custom hours)
- Perfect for pranks, tests, or temporary viewing changes

**Why it's safe:** Changes are only visible in the app and never saved. Original messages stay untouched in your SMS database.
